\chapter{Module Communication and Contracts}

\section{Communication principles}

\begin{enumerate}
\item Use direct application interfaces for short, local, request/response operations.
\item Use asynchronous jobs/events for slow, retryable, or externally dependent operations.
\item Use durable event records for inbound webhooks and outbound deliveries.
\item Keep public provider payloads at the adapter boundary; convert them to canonical internal contracts.
\item Never use an LLM prompt as the only interface contract between modules.
\item Carry \code{tenant\_\allowbreak{}id}, \code{correlation\_\allowbreak{}id}, \code{causation\_\allowbreak{}id}, and \code{occurred\_\allowbreak{}at} on internal events.
\item Version public/event contracts and make consumers tolerant of additive fields.
\item Do not expose internal-only endpoints publicly.
\end{enumerate}

\section{Asynchronous events/jobs}

Suggested event names:

\begin{itemize}
\item \code{conversation.\allowbreak{}created}
\item \code{message.\allowbreak{}received}
\item \code{message.\allowbreak{}persisted}
\item \code{ai.\allowbreak{}turn.\allowbreak{}requested}
\item \code{ai.\allowbreak{}turn.\allowbreak{}completed}
\item \code{tool.\allowbreak{}execution.\allowbreak{}requested}
\item \code{tool.\allowbreak{}execution.\allowbreak{}completed}
\item \code{human.\allowbreak{}handoff.\allowbreak{}requested}
\item \code{human.\allowbreak{}handoff.\allowbreak{}accepted}
\item \code{ticket.\allowbreak{}created}
\item \code{knowledge.\allowbreak{}source.\allowbreak{}ingestion.\allowbreak{}requested}
\item \code{knowledge.\allowbreak{}source.\allowbreak{}ingestion.\allowbreak{}completed}
\item \code{channel.\allowbreak{}delivery.\allowbreak{}requested}
\item \code{channel.\allowbreak{}delivery.\allowbreak{}completed}
\item \code{channel.\allowbreak{}delivery.\allowbreak{}failed}
\item \code{voice.\allowbreak{}session.\allowbreak{}started}
\item \code{voice.\allowbreak{}session.\allowbreak{}ended}
\item \code{evaluation.\allowbreak{}run.\allowbreak{}completed}
\item \code{usage.\allowbreak{}recorded}
\end{itemize}
Events communicate facts that have happened. Commands request work. Do not use event names that imply success before the work has succeeded.

\section{Delivery state machine}

Recommended outbound states: \code{queued \ensuremath{\rightarrow} sending \ensuremath{\rightarrow} sent \ensuremath{\rightarrow} delivered} with side paths: \code{queued/\allowbreak{}sending \ensuremath{\rightarrow} retry\_\allowbreak{}wait \ensuremath{\rightarrow} sending} and terminal or review states: \code{failed}, \code{cancelled}, \code{unknown}.

\code{sent} and \code{delivered} are distinct when the provider exposes a delivery receipt. An uncertain provider timeout must not automatically mean the message was not sent; retrying may duplicate it.

\section{Reliability patterns}

\begin{itemize}
\item \textbf{Webhook inbox:} persist provider event IDs and processing state to deduplicate replays.
\item \textbf{Transactional outbox:} commit domain changes and pending event records in one transaction, then publish.
\item \textbf{Idempotent commands:} use stable idempotency keys for external write operations.
\item \textbf{Retry policy:} exponential backoff with jitter, maximum attempts, and dead-letter/review path.
\item \textbf{Concurrency:} protect conversation ownership and turn sequencing.
\item \textbf{Ordering:} order by conversation/stream key when the broker supports partitioning.
\item \textbf{Timeouts:} bound all provider calls.
\item \textbf{Circuit breaking:} stop repeatedly calling a failing dependency.
\item \textbf{Compensation:} define recovery for workflows that span systems without distributed transactions.
\end{itemize}
\section{Error contract}

Return stable machine-readable error codes, safe user-facing messages, retryability, and correlation ID. Do not return stack traces, secret values, provider tokens, or internal prompts.
