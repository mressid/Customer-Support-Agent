\section{Roles and usage rules}

Every technology has a defined \textbf{role} (what it is for) and a \textbf{rule} (how the team must use it). The rules protect the architecture constraints: tenant isolation, provider portability, durable commits, and untrusted AI output.

\subsection{Security}

\begin{itemize}
\item Row-level security, tenant-aware repositories, and cross-tenant tests in CI.
\item Input validation with Zod and Ajv, output validation for model results.
\item Secrets in a manager, scanned with gitleaks, rotated and revocable.
\item Webhooks verified by HMAC signature and timestamp, deduplicated by event id.
\item File uploads checked by content type, size and malware scan.
\item Prompt injection tests in the evaluation suite and in the security checklist.
\end{itemize}
\subsection{Observability}

\begin{itemize}
\item OpenTelemetry traces across API, worker, model, retrieval and tools.
\item Structured logs with pino, redaction of sensitive fields, trace ids on every line.
\item Metrics for latency, errors, queue depth, token usage, cost, and voice quality.
\item Dashboards and alerts per tenant-safe label set.
\end{itemize}
\subsection{Testing and quality}

\begin{itemize}
\item Test pyramid: unit, integration with real Postgres, contract tests for adapters, end-to-end for UI.
\item AI evaluation set in Git, run on every agent or prompt change.
\item Resilience tests: duplicate webhooks, tool timeouts with unknown outcome, provider outages.
\item Load and recovery drills before Release 1.
\end{itemize}
\subsection{Delivery}

\begin{itemize}
\item Docker image built once and promoted through environments.
\item Terraform for infrastructure, feature flags for rollout, canary tenants first.
\item Rollback by disabling a flag or reverting the agent version.
\end{itemize}
