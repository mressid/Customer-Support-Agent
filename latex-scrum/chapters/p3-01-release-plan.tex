\section{Release goals}

\subsection{R1 --- Text support MVP}

\textbf{Outcome:} website visitor receives knowledge-grounded answers, one read-only business lookup is available, and human handoff preserves context.

Exit criteria:

\begin{itemize}
\item tenant isolation tests pass;
\item inbound messages are deduplicated;
\item unknown/unsupported questions have safe fallback;
\item tool calls are allowlisted, authorized, and audited;
\item human can take over;
\item core API/worker telemetry is available;
\item evaluation suite has no unresolved critical policy failure.
\end{itemize}
\mmdfig{07-scrum-release-risks/05-release-1-text-mvp}{Release 1 exit criteria}{fig:07-scrum-release-risks-05-release-1-text-mvp-87}


\subsection{R2 --- Voice MVP}

\textbf{Outcome:} customer can speak with the same AI engine and see a coherent transcript.

Exit criteria:

\begin{itemize}
\item session start/stop and cleanup are reliable;
\item transcript finalization and ordering work;
\item interruption behavior is tested;
\item audio/transcript privacy policy is implemented;
\item latency/cost metrics are visible;
\item human handoff behavior is validated for the selected provider.
\end{itemize}
\mmdfig{07-scrum-release-risks/06-release-2-voice-mvp}{Release 2 exit criteria}{fig:07-scrum-release-risks-06-release-2-voice-mvp-88}


\subsection{R3 --- Operational expansion}

\textbf{Outcome:} support teams can scale operations with workflows, routing, additional channels and stronger evaluation.

\section{Decisions not to make prematurely}

\begin{itemize}
\item One microservice per module
\item A universal workflow builder before core support works
\item Multiple speech providers before the first voice use case is validated
\item Autonomous write access to every customer system
\item Permanent raw audio retention
\item Complex subscription/billing before pricing and usage requirements are known
\end{itemize}
