\chapter{Product Vision and Scope}

\section{Vision}

Build an AI-native customer support platform that can conduct complete, context-aware customer conversations over text and voice, answer using trusted business knowledge, perform explicitly authorized actions, and transfer to human agents when appropriate.

\section{Primary users}

\begin{itemize}
\item \textbf{Customer:} asks questions or requests an action using a supported channel.
\item \textbf{Support agent:} reviews, takes over, and resolves conversations or tickets.
\item \textbf{Support lead:} manages queues, policies, reporting, and quality.
\item \textbf{Organization administrator:} configures channels, knowledge, AI agents, integrations, and access.
\item \textbf{Platform operator:} monitors reliability, cost, abuse, and platform health.
\end{itemize}
\section{Product outcomes}

\begin{itemize}
\item Reduce time to a correct answer.
\item Resolve repetitive requests without removing access to human support.
\item Preserve context across text/voice and channel changes where identity can be safely linked.
\item Make AI actions auditable and permission-controlled.
\item Let organizations configure knowledge, tools, policies, and escalation behavior.
\item Measure resolution quality, not only response speed.
\end{itemize}
\section{Product principles}

\begin{enumerate}
\item \textbf{Conversation-first:} a conversation is the durable interaction record; channel sessions are delivery mechanisms.
\item \textbf{Modality-independent intelligence:} text and voice share the same orchestration and authorization model.
\item \textbf{Grounded answers:} use approved knowledge and business data; be transparent about uncertainty.
\item \textbf{Safe action execution:} models propose tool calls; application services authorize and execute them.
\item \textbf{Human escape hatch:} customers can request human support and policy can escalate automatically.
\item \textbf{Tenant isolation by default:} organization boundaries apply to data, search, tools, events, and analytics.
\item \textbf{Observable and testable:} every important AI decision, tool execution, handoff, and failure is measurable.
\item \textbf{Provider portability:} model, speech, channel, and integration providers are accessed through adapters.
\end{enumerate}
\section{MVP scope}

\subsection{Included}

\begin{itemize}
\item Organization and user access foundation
\item Website text chat
\item Conversation lifecycle and message persistence
\item Basic customer identity
\item Knowledge source ingestion and retrieval
\item AI response orchestration
\item One read-only business tool
\item Human handoff/inbox
\item Basic ticket creation
\item Audit, logs, metrics, traces, and usage tracking
\end{itemize}
\subsection{Later phases}

\begin{itemize}
\item Real-time browser voice
\item STT/TTS and speech-to-speech provider options
\item Email and external messaging channels
\item Workflow builder and advanced routing/SLA
\item More connectors and write-capable tools
\item Advanced analytics, evaluation, billing, and enterprise governance
\end{itemize}
\section{Explicit non-goals for the first milestone}

\begin{itemize}
\item Replacing all existing CRM/helpdesk systems
\item Arbitrary autonomous changes to customer accounts
\item Unreviewed financial transactions
\item Supporting every channel/provider at launch
\item Training a foundation model
\item Splitting every module into a microservice
\end{itemize}
\section{Success measures}

\begin{itemize}
\item Correct answer rate on a curated evaluation set
\item Groundedness/source support rate
\item Successful task completion rate
\item Human escalation rate, segmented by reason
\item Median and p95 response latency
\item Tool success/failure rate
\item Customer satisfaction
\item Cost per resolved conversation
\item Availability and message-delivery success
\end{itemize}
