\section{Data rules}
\begin{itemize}
  \item All tenant-owned rows include, or are reachable through, a trusted organization ID.
  \item Internal identifiers are UUIDs or ULIDs; provider IDs are kept in separate fields with uniqueness scoped to the provider connection.
  \item Phone number or e-mail is never the primary key of a customer.
  \item Timestamps are stored in UTC and rendered in local time at the edge.
  \item Raw provider payloads are kept only when needed for debugging or compliance, with explicit retention and redaction.
  \item Agent configuration, knowledge documents, workflows and tool schemas use immutable version rows.
  \item Messages, transcripts, audio references and attachments stay distinct so retention and access policies can differ.
  \item Large binary payloads are stored as object references, not in the primary relational database.
  \item Deletion and re-indexing propagation of knowledge sources is recorded.
  \item Hidden chain-of-thought is not stored; only concise decision metadata, tool calls, sources and outcomes needed for debugging and audit.
\end{itemize}
