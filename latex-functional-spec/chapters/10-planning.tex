\subsection{R1 exit criteria}
\begin{itemize}
  \item tenant-isolation tests pass;
  \item inbound messages are deduplicated;
  \item unknown or unsupported questions have a safe fallback;
  \item tool calls are allowlisted, authorized and audited;
  \item a human can take over;
  \item core API and worker telemetry is available;
  \item the evaluation suite has no unresolved critical policy failure.
\end{itemize}

\subsection{R2 exit criteria}
\begin{itemize}
  \item session start, stop and cleanup are reliable;
  \item transcript finalization and ordering work;
  \item interruption behaviour is tested;
  \item the audio and transcript privacy policy is implemented;
  \item latency and cost metrics are visible;
  \item human handoff behaviour is validated for the selected provider.
\end{itemize}

\section{Constraints}
\begin{itemize}
  \item \textbf{Architecture:} modular monolith first; the core domain does not depend on any specific provider.
  \item \textbf{Security:} AI output is untrusted; authorization is enforced in code.
  \item \textbf{Privacy:} no raw audio or sensitive data retained without need, consent and policy.
  \item \textbf{Organization:} small team; capacity and calendar unknown; dates are placeholders.
  \item \textbf{Dependencies:} voice and integration work depend on vendor capabilities and credentials.
\end{itemize}

\section{Decisions to record and to defer}
\textbf{Architecture decision records to create:} ADR-001 modular monolith boundaries; ADR-002 relational database and tenant isolation; ADR-003 queue and outbox/inbox; ADR-004 knowledge ingestion and vector search; ADR-005 LLM provider abstraction and data policy; ADR-006 voice strategy (modular STT/TTS versus speech-to-speech); ADR-007 browser voice transport and telephony; ADR-008 transcript and audio retention and consent; ADR-009 authentication and customer verification; ADR-010 tool authorization and approval.

\textbf{Decisions not to make prematurely:} one microservice per module; a universal workflow builder before core support works; several speech providers before the first voice use case is validated; autonomous write access to every customer system; permanent raw audio retention; complex billing before pricing and usage are known.
