\chapter{Domain Model}

\section{Core aggregate boundaries}

\begin{itemize}
\item \textbf{Organization:} tenant boundary and configuration owner.
\item \textbf{Conversation:} durable interaction and message timeline.
\item \textbf{Customer:} profile and verified identity links.
\item \textbf{Agent configuration/version:} published AI behavior and allowed capabilities.
\item \textbf{Knowledge source/document version:} ingestion and retrieval lifecycle.
\item \textbf{Tool execution:} authorization, idempotency, result, and audit.
\item \textbf{Ticket:} support work item that can span conversations.
\item \textbf{Voice session:} live media lifecycle linked to a conversation.
\item \textbf{Workflow run:} deterministic multi-step execution.
\item \textbf{Audit/usage event:} immutable record for governance and measurement.
\end{itemize}

\section{Data modeling rules}

\begin{itemize}
\item All tenant-owned rows must include or be reachable through a trusted \code{organization\_\allowbreak{}id}.
\item Use internal UUIDs/ULIDs; keep provider IDs in separate fields with uniqueness scoped to provider/connection.
\item Avoid using phone number/email as the primary key for a customer.
\item Store timestamps in UTC; render local time at the edge.
\item Keep external provider payloads only when needed for debugging/compliance and with explicit retention/redaction.
\item Prefer immutable version rows for agent configuration, knowledge documents, workflows, and tool schemas.
\item Keep messages, transcripts, audio references, and attachments distinct so retention/access policies can differ.
\item Store object references rather than large binary payloads in the primary relational database.
\item Record deletion and re-indexing propagation for knowledge sources.
\item Do not store hidden chain-of-thought. Store concise decision metadata, tool calls, sources, and outcomes needed for debugging and audit.
\end{itemize}
\section{Suggested message kinds}

\begin{itemize}
\item \code{text}
\item \code{image\_\allowbreak{}reference}
\item \code{file\_\allowbreak{}reference}
\item \code{audio\_\allowbreak{}reference}
\item \code{system\_\allowbreak{}event}
\item \code{internal\_\allowbreak{}note} (not customer-visible)
\item \code{transcript\_\allowbreak{}segment} (if transcript is modeled in the message timeline)
\end{itemize}
Use explicit visibility and direction fields rather than relying on message text conventions.
